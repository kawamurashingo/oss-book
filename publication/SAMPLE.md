# 試し読みPDFの生成（技術書典用候補）

## 方針

試し読みを別原稿から作らず、**同じビルドで生成された全編PDFの冒頭12ページ**を抜き出します。表紙、目次、最初の本文の実際の組版を確認できます。

- 全編と試し読みが食い違うことを防ぐため、ページ抽出のみで生成します。
- ただし、**試し読み範囲より先の章へ飛ぶ目次リンクは自動で削除**します。試し読み内で有効な章リンクと外部URLリンクは残し、文章と見た目は変更しません。
- `scripts/build_sample.py` は全編ファイルを上書きできません。
- **試し読みの要求ページ数が全編以上なら失敗**させます。原稿全体を試し読みとして公開する事故を避けます。
- 抜き出したページには「試し読み」の透かしを入れません。PDFメタデータに試し読みであることを記載します。見本の内容は頒布本と一致しますが、見本の公開前には改めて著者が確認してください。
- 現行A5判では12ページの末尾で第2章が終わり、13ページから第3章が始まります。**ページ位置は組版が変わると動く**ため、CIで13ページの章見出しを確認します。区切りが変わった場合はビルドを停止し、範囲を再検討します。
- 読みやすさ、冒頭12ページの区切りがよいかは著者レビューで調整可能です。**試し読みページ数・販売価格を確定したわけではありません。**

## 生成方法

```sh
python3 -m pip install -r requirements-build.txt -r requirements-sample.txt
python3 scripts/build_release.py
python3 scripts/build_sample.py --pages 12
```

出力：`output/oss-book-sample.pdf`

GitHub Actionsの `Build sample PDF preview` でも自動生成し、プレビュー用のArtifactとして保存します。自動で技術書典へアップロード・公開することはありません。
